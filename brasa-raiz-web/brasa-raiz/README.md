# Brasa & Raíz · Página web responsiva de restaurante

Proyecto de maquetación con HTML5, CSS3 (Flexbox y Grid) y JavaScript vanilla.

## Estructura

```
brasa-raiz/
├── index.html        Estructura principal (semántica HTML5)
├── css/styles.css    Estilos, variables y media queries
├── js/main.js        Menú móvil, pestañas y validación del formulario
├── img/              Logotipo, ilustración del hero e ilustración de platos (SVG)
└── README.md
```

## Ejecución

Abre `index.html` en el navegador, o sirve la carpeta localmente:

```
python3 -m http.server 8000
```

Luego visita http://localhost:8000.

## Puntos de quiebre

| Resolución        | Ancho           |
|-------------------|-----------------|
| Móvil (base)      | menos de 600 px |
| Tableta pequeña   | desde 600 px    |
| Tableta           | desde 768 px    |
| Escritorio        | desde 1024 px   |
